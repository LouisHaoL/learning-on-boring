## 0. 一句话总纲

把地球摊平,在数学上**注定失真**。因此地图投影的本质不是"画得准",而是**选择失真发生在哪里**——而"哪里失真"从来不只是数学问题,它塑造了亿万人对世界的想象,也引发过一场真正的舆论战争。

## 1. 核心数学事实:球面不可展

### 1.1 高斯曲率与绝妙定理

【数学】球面是正高斯曲率曲面(半径 R 的球面 K = 1/R²),平面 K = 0。高斯在 1827 年的《曲面的一般研究》(Disquisitiones generales circa superficies curvas)中证明的 **Theorema Egregium(绝妙定理)** 指出:高斯曲率在等距变换(即不拉伸、不撕裂的"摊平"操作)下不变。既然 1/R² ≠ 0,球面**不可能**被等距摊平到平面上——任何地图投影必然在面积、角度、距离三者中至少牺牲一样,通常三者皆失真。

一个直观推论:【数学】**不存在既保面积又保形状(等角)的投影**。等角要求局部形状不变形,等积要求面积比不变,拉普拉斯方程层面的推导表明两者不可兼得(Snyder, *Map Projections: A Working Manual*, USGS PP 1395, 1987)。

值得注意的时间差:【史实】墨卡托(1569)与兰伯特(1772)造出完美等角/等积投影时,"为什么永远造不出全能投影"的证明(1827)还不存在。地图学家先凭经验做出了正确的工程取舍,数学家一个半世纪后才证明这取舍是**被迫的**。

### 1.2 Tissot 指标线:给失真画一张 X 光片

【数学】1881 年,法国数学家 Nicolas Auguste Tissot 提出指标线(indicatrix):在球面上画一个无穷小圆,投影后它一般变成一个**椭圆**。椭圆的两条半轴 a、b 就是两个主方向的局部比例尺:

- **面积失真** = a·b(等积投影恒为 1)
- **角度失真** = a/b 与 1 的偏离(等角投影恒有 a = b,即圆仍是圆,只是被放大)

把指标线铺满整张地图,失真的空间分布一目了然。这是现代投影比较的标准工具(USGS *An Album of Map Projections*, PP 1453, 1989)。

文字示意:同一片格陵兰上,三类投影的指标线长相迥异——

```
等角(墨卡托)            等积(摩尔威德)         折衷(温克尔三重)
  ○ → 放大成大圆           ○ → 扁椭圆              ○ → 略被拉长的椭圆
  (圆仍是圆:形状对,       (面积对,但东西向         (面积、形状各让一步:
   面积狂涨 sec²φ)          被压扁 ~40%)             两边都不极端)
```

判读规则:圆 = 保角;等面积比 = 保积;两者不可兼得,只能谈"哪个偏得少"。

### 1.3 投影三角:只能择一而从

"距离"在曲面上无处不真(测地线长度是积分量),所以真正可全局保住的是两个性质:面积与角度。于是经典分类是一个三角:

```
              等角 (Conformal)
              /          \
     局部形状准           方向/角度准(航海!)
            /              \
   等距 (Equidistant) —— 等积 (Equal-area)
     沿特定线距离真          面积真,形状烂
            \              /
              折衷 (Compromise)
              全都失真一点,全都不太离谱
```

- **等角**:球面到平面的等角映射由高斯与欧拉(1777)研究透。典型:墨卡托、兰伯特等角圆锥。
- **等积**:典型:兰伯特方位等积(1772)、阿尔伯斯(1805)、摩尔威德(1805)。
- **等距**:只能在特定线(如从某中心出发的所有大圆方向)上保距离,典型:方位等距。
- **折衷**:承认"没有一种失真最重要",把总失真做小,典型:罗宾森(1963)、温克尔三重(1921)。

【数学】还有一类"作弊"方案:**分瓣/断裂投影**(如古德同相投影,1925)——在海洋上切开地图,让每瓣大陆各自接近等积。代价是海洋被撕碎,经纬网断裂,但它证明了:如果愿意破坏地图的"连续性",失真预算可以重新分配。

## 2. 墨卡托(1569):为航海而生,被教科书绑架

### 2.1 航海动机:等角航线画成直线

【史实】1569 年,佛兰德制图师 Gerardus Mercator 出版《为航海者修订的全新且完备的世界描述》(Nova et aucta orbis terrae descriptio ad usum navigantium emendate accommodata)。当时远洋航行靠罗盘沿**等角航线(loxodrome / rhumb line)**走——与所有经线保持固定交角的螺旋线。在球面上它是螺旋,画在任何旧地图上都是曲线,舵手无法照着直尺走。

墨卡托的天才在于:让纬线随纬度升高按 sec φ 拉伸(经线也同理拉伸),于是**所有等角航线变成直线**。舵手连两点、量方位角,罗盘照走,全程无需改算。【数学】这等价于投影保角(等角),而"sec φ 累加"正是积分 ∫sec φ dφ,其解析形式(arctanh 形式)直到 1645 年前后才由 James Gregory 等人得出。【史实】墨卡托本人从未发表其数学;爱德华·赖特(Edward Wright)在 1599 年用"逐度累加 sec φ"的数值表首次给出了正确解释与作图法(Monmonier, *Rhumb Lines and Map Wars*, 2004, ch. 1)。

理解这项发明的历史语境,才能理解它的"纯度":

- 【史实】墨卡托(1512-1594)是当时欧洲最重要的地球仪与仪器制作师之一,一生曾因地图触怒宗教当局(1544 年因涉嫌新教异端入狱);他的本业是做"工具"而非做"宣传"。
- 【史实】1569 年地图的全名里写着"ad usum navigantium"(供航海者使用)——这是一份**面向专业用户的功能说明书**,不是给小学生的世界入门图。夸大的北海区域恰恰是当时航海最密集、最需要精确保角的区域;面积失真是他**付得起的代价**。
- 【史实】即便如此,这张图在 16 世纪也嫌"超前":当时的航海实践中更通行平面航法(plane sailing,直接把海当平面算),墨卡托投影要到 17 世纪才真正成为海图标配(Monmonier 2004)。一项"为极限精度而生"的工具,其普及同样滞后于发明——与后来 Web 墨卡托"先上线、后标准化"的节奏遥相呼应。

### 2.2 代价:高纬度面积爆炸

【数学】墨卡托投影中,任一点的面积比例尺为 sec²φ。失真随纬度的变化:

```
纬度    面积放大倍数 (sec²φ)        语义
 0°            1.0                赤道:真面积
30°            1.33               中低纬:开始夸大
45°            2.0                欧洲大部:翻倍
60°            4.0                斯堪的纳维亚、加拿大南部
80°           33.2                格陵兰北部
90°            ∞                  极点被推到无穷远(地图必须截断)
```

【数学】于是有了著名对比(面积数据为测绘事实):

- 非洲 ≈ 3037 万 km²,格陵兰 ≈ 217 万 km²,**真实比例约 14 : 1**
- 在墨卡托地图上,两者**看起来差不多大**——格陵兰被放大约 14 倍,非洲(横跨赤道)几乎不放大。

【史实】讽刺的是,墨卡托的地图在 16-17 世纪航海界是专业工具,而它成为"人们心中的世界"主要发生在 19-20 世纪:印刷商与教科书发现这种**矩形、经纬线垂直、方向感清晰**的地图好印好挂,纷纷采用,航海界自己反而更常用兰伯特等角圆锥等图。20 世纪中叶起,专业地图学界已反复批评出版界滥用墨卡托(Hinks 1912、Steers 1927、Kellaway 1946 等教材均有明确抱怨,见 Gall–Peters 词条引文)。

## 3. 投影家族漫游:一部"没有赢家"的工程史

所有投影都从"如何把可展面(圆柱、圆锥、平面)贴到球上,或干脆放弃可展几何"衍生。三大几何原型的文字示意:

```
 圆柱投影                圆锥投影                方位投影
   ______                 ___/\___                  ___
  |      | <- 展开成矩形  /        \ <- 展开成扇形  /     \ <- 投到切平面
  |______|               \___    ___/    ____      |  +  |    (极点最准,
     ||                        \  /    /    \      |_____|     离切点越远
   [sphere]                    \/    [sphere]    [sphere]      越失真)
```

圆锥投影的关键自由度是**切在/割在哪条纬线**上:标准纬线处零失真,向两侧线性增大——这正是中纬度国家(美、中、欧)区域图的默认方案。

主要家族与代表:

| 家族 | 几何直观 | 代表投影(年代) | 典型用途 |
|---|---|---|---|
| 圆柱 | 球外包圆柱,展开成矩形 | 墨卡托(1569)、**等距圆柱/Plate Carrée**、兰伯特等积圆柱(1772)、**Gall–Peters** | 航海、Web 地图、世界挂图 |
| 圆锥 | 球内圆锥,展开成扇形 | **兰伯特等角圆锥**(1772)、阿尔伯斯等积(1805) | 中纬度国家/区域图、航空图 |
| 方位 | 投到切平面上 | **兰伯特方位等积**(1772)、**方位等距**(极地航图)、正射(看月球般看地球)、球心(gnomonic,所有大圆成直线) | 极地图、航空、地震定位 |
| 伪圆柱 | 纬线直、经线弯成弧 | **摩尔威德**(1805)、正弦(可回溯到 16 世纪)、罗宾森(1963) | 世界专题图、教科书 |
| 多圆锥/折衷 | 混合构造 | **温克尔三重**(1921)、**罗宾森**(1963) | 国家地理(1998 后)、教科书 |
| 分瓣 | 沿选定的"不重要的线"切开 | **古德同相**(1925)、分瓣正弦 | 专题统计地图集 |
| 多面体 | 球贴到多面体再展开 | **Fuller Dymaxion**(1943)、**Waterman**(1996)、**AuthaGraph**(1999) | 艺术与观念地图 |

几个值得记住的细节:

- **罗宾森投影**是 1963 年 Rand McNally 委托 Arthur Robinson 用"调参+目视评价"而非纯公式造出的,是"折衷"哲学的宣言(Robinson 自述,见 Snyder 1993)。
- **温克尔三重**取"方位等距"与"艾托夫"投影坐标的加权平均,名字里的"三重"指它同时折衷面积、角度、距离三种失真。1998 年起成为《国家地理》官方世界地图投影,至今沿用。
- **球心投影**虽在航海上烂(面积角度俱毁),但**任何大圆(最短航线)成直线**,故在航空/航海的"航线规划图"上不可替代——又一个"为特定任务选特定失真"的例子。

## 4. 历史与政治:Peters 之争——地图学史上最大的舆论战

### 4.1 事件的戏剧结构

【史实】1973 年,德国电影制片人兼历史学家 Arno Peters 发布"彼得斯世界地图",宣称它"面积完全正确",纠正墨卡托把欧洲/北美画得过大、把全球南方压小的"殖民偏见"。他的论点击中了时代神经:

- 教会与发展组织(如美国基督教会全国委员会、New Internationalist 杂志)大量采用;UNESCO 也推广过;英国学校广泛使用(Wikipedia "Gall–Peters projection" 条目,2026-09 查证)。
- Peters 在《新制图学》(1983)中直接指控整个制图行业:"自墨卡托为欧洲统治世界的时代绘制地图以来的四百年里,制图师们死抱住它不放……这一行业基于欧洲中心的旧信条,无力发展出能体现各民族平等的世界地图。"(Peters, *The New Cartography*, 1983)

### 4.2 学界的反弹:三个致命反驳

【史实+数学】专业地图学家的反击集中在三点:

1. **"唯一"是谎言**:等积投影是制图学最古老的门类之一(正弦投影可溯至 16 世纪,兰伯特 1772 年即给出方位等积与圆柱等积),已描述的有数百种。Peters 声称其地图是仅有的"面积正确"地图,且还宣称其"绝对保角""无极端形状失真""完全保距"——每一条都不成立(Snyder, *Flattening the Earth*, 1993, p.165;Robinson 1985)。
2. **并非首创**:该投影就是苏格兰牧师 James Gall 于 1855 年提出、1885 年正式发表的"Gall 正交投影",标准纬线同为 45°。"Gall–Peters"这个名字正是 Robinson 在 1986 年美国地图学协会(AAC)小册子中首创,用以点破"新发现"的虚妄。
3. **它自己也有欧洲 bias 的讽刺**:Gall–Peters 在 45°N/S(恰好穿过 Peters 的祖国德国所在的纬度带)零失真,把形状失真的代价全部压给赤道带的低纬国家——被批评为"用另一种欧洲中心主义反欧洲中心主义"(Snyder, "Social Consciousness and World Maps", *Christian Century*, 1988)。

【争议/观点】持平而论:Crampton(1994)《制图学的决定性时刻》等后续研究承认,Peters 的数学与学术操守不堪一击,但他**赢了舆论**——他逼整个行业公开承认:墨卡托矩形世界地图在教科书和媒体上的泛滥确实是一种应被纠正的错误。J. B. Harley 认为这场争论证明了投影的社会后果真实存在。

### 4.3 1989 年决议:"拒绝一切矩形世界地图"

【史实】1986 年起 AAC 出版《Which Map Is Best》系列小册子向公众科普投影失真;1989-1990 年,北美七个地理/制图组织(美国地图学协会、美国地理学会、加拿大制图协会等)通过决议,**拒绝一切矩形世界地图**——注意这个措辞同时打击了墨卡托和 Gall–Peters(Robinson, "Rectangular World Maps—No!", *Professional Geographer*, 1990)。唯一公开拒绝签署的是 NACIS(北美地图信息学会),其成员 Denis Wood 后来称这是"几乎整个行业都背书了一个愚蠢决议"(Wood, *Cartographic Perspectives*, 2003)。

【争议/观点】这个决议常被误读为"禁用墨卡托"。它只针对**世界全图**:墨卡托作为区域图/航海图/导航底图依然是合法且优秀的工具。学界真正想反对的是矩形世界挂图这种"为版面好看而牺牲地理真相"的习惯。这场内部争议(NACIS 的反对)预示了后来"地图学界是否越权替公众做审美决定"的长期辩论。

【史实】尾声:《国家地理》1988 年弃用墨卡托改用罗宾森,1998 年再改温克尔三重;2017 年波士顿公立学校宣布改用 Gall–Peters 等积地图引发新一轮报道;2024 年内布拉斯加州立法要求公立学校展示等积或 AuthaGraph 地图(Wikipedia, 同上)。

### 4.4 舆论战复盘:为什么"错误的一方"赢了传播

这场争论常被简化为"科学战胜炒作"或"专家傲慢压制改革",两个说法都不准。拆开看攻防结构更有教益:

- **叙事优势**:Peters 卖的不是投影,是一个**道德故事**(谁的地图?谁被缩小了?);地图学家们回应的是**技术事实**(它 1855 年就有了、它不保角、等积投影有几百种)。道德故事五分钟讲完,技术事实需要一学期。
- **学界的结构性失位**:【史实】批评者完全正确,但他们此前三十年对教科书滥用墨卡托的书面批评(Hinks 1912 起有据可查)从未走出专业期刊——直到被 Peters 的公关羞辱才被迫面对公众。Peters 没有击败制图学,他击败的是制图学的**沉默**。
- **双输但有遗产**:等积地图从此进入公众词汇,Equal Earth(2018)等新一代兼顾美观的等积投影正是对"既等积又别太丑"这一战后需求的回应;而"拿一张地图当道德宣言"的模板,也被后来各种宣传性地图反复套用。

【争议/观点】Crampton 的判词最公允:这是制图学的"决定性时刻"——不是因为谁对了,而是因为行业第一次被迫公开承认**地图从来不中立**。

## 5. 现代实践:Web 墨卡托如何统治互联网

### 5.1 它是什么

【史实+数学】2005 年 Google Maps 上线,采用"球面墨卡托":把 WGS84 椭球坐标**当作球面坐标**代入正球墨卡托公式,再把地图在 ±85.0511° 纬度截断(使地图正好是正方形,便于瓦片金字塔:每个缩放级别把世界切成 2^n × 2^n 张 256px 方瓦,每块区域恒有唯一瓦片编号)。这个坐标系统后来被注册为 **EPSG:3857**(民间曾戏称 EPSG:900913——"GOOGLE" 的 leet 写法),微软 Bing、OpenStreetMap 等随即跟进,成为互联网地图的事实标准(Wikipedia "Web Mercator projection";epsg.io/3857)。

### 5.1b 瓦片金字塔的数学(复算验证)

截断纬度不是拍脑袋:令"从赤道到纬度 φ 的墨卡托 y 坐标"等于"赤道到极点距离的一半",解出 φ = arctan(sinh π) = **85.05113°**(本次小实验复算与 EPSG 注册值一致)。地图因此成为以赤道周长为边长的正方形,可被整齐地四叉切分。

```
缩放级 z:  0        1        2   ...   z
瓦片数:    1×1      2×2      4×4  ...  2^z × 2^z
赤道米/像素: 156,543  78,272  39,136 ...  156,543,034 / 2^z
```

代入 256px 瓦片与赤道周长 40,075,016.686 m,可算出:z=0 时每像素约 **156.5 公里**;z=10(看城市)约 **153 米**;z=19(看街区)约 **0.30 米**——已贴近民用卫星影像的物理分辨率。每一级分辨率恰好减半,这个规整性正是 CDN 缓存与"放大不重新请求全图"的前提。

### 5.2 为什么"数学上糟糕"却赢了

这是本文要论证的核心:**Web 墨卡托的胜利不是制图学判断,而是系统工程判断,外加一点地缘惰性。**

1. **瓦片是平方数,缓存是命根子**。方形、等经差的瓦片让任意缩放级、任意区域都对应确定的数据块,全球瓦片金字塔可预生成、可 CDN 分发、相邻缩放级四叉树复用。等积投影(如摩尔威德)的弯曲经线会把瓦片切得七零八落,缓存失效爆炸。【观点→工程事实】这一条几乎单枪匹马决定了胜负。
2. **高缩放级别下,失真趋近于零**。墨卡托的 sec²φ 面积爆炸是全球性惩罚;但用户 95% 的时间在看街区——在城市尺度,任意投影的局部失真都不可感知,而墨卡托的**保角性**反而成为优点:街角不歪,建筑物形状正确,与正射影像对齐。【数学】等角性对小尺度地图是切实红利,不是奢侈品。
3. **北永远朝上、方向感统一**。用户十几年间在所有产品中建立了同一空间直觉,后来者(Bing、OSM、高德/腾讯海外版)跟随标准的成本远低于另起炉灶。这是典型的**网络效应锁定**,与当年矩形教科书地图的泛滥逻辑同构。
4. **Google 的真实取舍**:【争议/观点】搜索"格陵兰 vs 非洲"在今天的一亿部手机上仍然呈现 1:1 而非 1:14——Google 在 2018 年起在低缩放级换成了 3D 地球模式,算是技术上的部分修正,但默认投影至今未变。合理的推断是:对 Google 而言,投影的政治问题被"高缩放时无关紧要、低缩放时用户已习惯"稀释了;批评者则认为这是把制造认知偏差的成本外部化给了公众。
5. **成本对比决定结局**:换投影对一家传统制图公司意味着重印一代挂图;对 Google 意味着重生成数十亿张预渲染瓦片、改动所有客户端的坐标管线,以及**与整个生态(OSM、Bing、无数 GIS 工具)脱钩**。当修正在经济上如此昂贵、而在用户体感上如此便宜时,不修正就成了理性选择——这不是墨卡托第二次"赢",而是锁定效应代替了任何人做决定。

### 5.3 官方测绘机构的抵抗

【史实】正因为"球面近似"牺牲了椭球精度,美国国家地理空间情报局(NGA)2014 年发布 **Advisory Notice on "Web Mercator"**:在任务关键应用中把 Web 墨卡托坐标当作真正的 WGS84 墨卡托使用,可造成**高达约 40 公里的定位误差**(GPS World, 2014-10 报道);EPSG 注册表对 3857 的官方备注也写着:相对椭球墨卡托(EPSG:3395)存在"最高约 0.7% 的比例尺误差与最高约 43 km 的北向偏差(对导航类用途无关紧要)"——官方原话承认它"够用但不是大地测量品"。这句话本身就是 Web 时代的投影哲学:**精度让位于可用性,再由工程手段(瓦片、缓存)把可用性放大为垄断。**

【争议/观点】一个值得玩味的闭环:1569 年墨卡托为船长的罗盘造投影,2005 年 Google 为程序员的缓存造投影——两次胜利都属于"把某一类用户的任务做到极致,把其他失真留给别人"的工程理性。而专业地图学界两次都站在批评席上,两次都未能阻止。

## 6. 有趣细节:乌托邦、蝴蝶与那张没有"正确答案"的世界

- **Fuller 的 Dymaxion 地图(1943)**:把世界投到正二十面体再展开。它保面积、可无限多种展开方式、且**没有唯一的"上"**——Fuller 刻意用它质疑"北在上"的权力构图,称之为"飞行汽车时代的活地图"。【争议/观点】它至今更多是观念艺术的丰碑而非实用工具:锯齿状边界让阅读者无法建立连续经纬网,而这恰恰是 Fuller 的本意之一。
- **Waterman 蝴蝶投影(1996)**:Steve Waterman 基于多面体结点数学的等积投影,形似蝴蝶,以"非洲居中、无北极夸大"的姿态进入课堂,可视为 Dymaxion 的低门槛后继者。(谱系注,R4 回顾补:蝴蝶形展开的更早源头是 Cahill 1909 年起的多面体世界地图,Waterman 是这条线的多面体后继——两者常被混称,注意区分。)
- **AuthaGraph(1999,鸣川肇)**:把地球分到 96 个三角形再贴到四面体展开,号称在矩形框架内把面积/形状/距离失真做得空前均衡,且可以无限平铺。2016 年获日本"优良设计奖"后一度成为"最公平地图"的媒体宠儿;2024 年内布拉斯加州立法将其列为学校可选地图之一。它能不能成为下一个 Gall–Peters(即:一个好想法被一轮舆论放大然后被学界检视),本身就是个进行中的案例。
- **Hobo–Dyer(2002)与"平价正义地图"运动**:美国马萨诸塞州的 ODT 公司把 Gall–Peters 与更温和的 Hobo–Dyer 等积投影做成教育套件,推动"比例公正的世界地图"进课堂(2001 年诺贝尔奖颁奖典礼、卡特中心都曾是它的展示场景;ODT 于 2020 年停业)。这条支线说明:等积地图的美国大众化走的是**商业+公益**路线,与当年 Peters 的**舆论战**路线互为镜像。
- **地图投影对公众认知的塑造是可测量的**:心理学与地理教育的多项研究(如 Saarinen 对全球学生"世界心智地图"的调查)发现,各国学生普遍高估欧洲的面积、低估非洲——与他们在教室里看到的投影高度相关。【争议/观点】相关不等于因果,但一个从墨卡托时代延续到推荐算法时代的机制已经足够清楚:**默认视图是最大规模的地理教育者**。
- **公众认知是被默认选项塑造的**:罗宾森/温克尔三重之所以重要,是因为它们出现在《国家地理》与教科书里——普通人一生可能不会主动选择一张投影,他们只是接受了别人替他们选择的失真。
- **同一张地图,颠倒过来就是另一种政治**:把墨卡托南朝上(McArthur 1979 年为澳大利亚制作的"修正版"世界地图),非洲和南美滑向视觉中心,欧亚"沉"到地图底部——数据未变,心理等级全变。这张"倒置地图"长期是澳大利亚课堂与纪念品店的畅销品,证明了:位置和大小一样,都是投影文本的一部分。

## 7. 常见误解澄清

**误解一:"格陵兰真的有那么大吗?"**
不大。【数学+史实】真实面积约 217 万 km²,约为非洲(3037 万 km²)的 **1/14**;在墨卡托地图上两者视觉面积接近,是因为格陵兰处纬度太高、被 sec²φ 放大。印度(约 329 万 km²)其实比格陵兰大,但几乎没人在墨卡托地图上看出这一点。注意:巴西、刚果、印尼等赤道国家在墨卡托上反而是**被低估**的。

**误解二:"Peters 投影是客观的吗?"**
它的**面积**是客观的(等积),但【数学】所有等积投影都必然严重扭曲形状,而 Gall–Peters 把形状失真的重灾区放在低纬度地区;它宣传中"唯一面积正确的地图""绝对保角"等说法历史上就是假的(Snyder 1993)。它是一张有明确价值观的地图,只是它宣称的价值观(为南方平反)与自己实际的失真分配(again 压向南方)存在张力。**没有"客观的世界全图",只有"公开说明自己牺牲了什么的世界全图"。**

**误解三:"墨卡托是殖民阴谋的产物。"**
【史实】不是。它是为航海安全的纯技术发明(保角航线),且在其后三百年主要服务于航海/军事专业用途。它进入教科书与世界挂图是 19-20 世纪出版惯性(矩形好印好挂)的结果,并非某个策划。【争议/观点】"惯性造成的偏见也是偏见"——批评它的政治效果是正当的,把它说成蓄意阴谋则既不符合史实,也让批评变得容易反驳。

**误解四:"1989 年决议禁用了墨卡托。"**
没有。决议只拒绝**矩形世界全图**;墨卡托作为区域图、航海图、以及任何中低纬导航底图,至今仍是专业首选之一。

**误解五:"Web 墨卡托既然是数学上错的,那 Google 地图的数据都是错的。"**
【数学】它有两个独立的"错":一是球面近似带来的椭球偏差(北向最高约 43 km,比例尺 0.7%,epsg.io/3857 备注);二是全球尺度的面积失真(与经典墨卡托相同)。但在街道级缩放,两者都小于屏幕一个像素所对应的地面距离的量级,对用户完全不可见。**错,但错在不被使用的地方**——这是工程判断而非科学判断,混为一谈会同时冤枉地图学和 Google。

**误解六:"有了 GPS,投影就不重要了。"**
GPS 给的是椭球上的坐标(EPSG:4326),而屏幕显示必须投影。今天地球上绝大多数人看到的"我在哪",都经过一次投影转换——通常是 Web 墨卡托。投影不是被技术淘汰的前现代遗物,而是每次打开地图都在重复执行的选择。

**误解七:"把地图南朝上(或换成 AuthaGraph),偏见就消除了。"**
【争议/观点】倒置地图(如 McArthur 的"南在上"澳大利亚版)确实是有效的认知震撼教育:它证明"北在上"是**约定**而非事实。但地图学界普遍认为这只解决构图问题,不解决失真分配问题——倒过来的墨卡托依然是墨卡托,只是把"谁被夸大"换了主角。真正要紧的是**公开失真说明**,而非寻找一张"政治正确"的正解。

**误解八:"投影误差会影响导航和外卖定位。"**
【数学+工程】两套误差量级完全不同:Web 墨卡托相对椭球墨卡托的偏差最高约 43 km(北向)与 0.7%(比例尺)——听起来吓人,但这是**全球最大偏差**,发生在高纬度;在中纬度城市(比如北纬 40° 的北京/纽约),量级小两个数量级以上,远小于手机 GPS 本身数米到数十米的定位噪声。你的外卖不会因此送错楼。真正受影响的只有大地测量与军事级任务——这正是 NGA 告示的对象(见 §5.3)。

## 8. 结论:投影之争的元教训

1. 【数学】失真不可消除,只能**显式地选择**;宣称"完美"或"唯一正确"的投影主张在数学上必然是骗局。
2. 【史实】一个投影的流行程度与其制图学质量**几乎无关**,取决于它服务谁的任务、多容易被印出来/缓存起来。墨卡托赢了两次,靠的都是把某一类任务做到极致。
3. 【争议/观点】投影是最小单位的认知政治:一张图的失真分配,决定了几代人心中"哪里重要"。地图学界的正当角色不是垄断选择权,而是**把每一次失真选择翻译成公众能懂的代价清单**——从 AAC 的小册子到今天 Google 隐藏在帮助文档角落里的投影说明,这条公共教育的路还没走完。
4. 【争议/观点】舆论战的胜负手是叙事而非事实,但沉默的专家同样有责:1569 年的墨卡托没有骗人,1973 年的 Peters 骗了人,可两次都是**默认选项**在塑造世界——无论是教科书编者的惰性,还是硅谷工程师的缓存表。对"默认值"保持警觉,是这四百五十年历史最便宜的学费。

一句话收束:地图投影史上没有一个骗子能骗过数学,但每一个默认设置都能骗过几十亿人。

## 10. 附:任务-投影速查(工程视角的"该选哪种失真")

| 你的任务 | 该牺牲什么 | 常用选择 | 理由 |
|---|---|---|---|
| 航海/罗盘导航 | 面积 | 墨卡托 | 等角航线成直线 |
| 中纬度国家区域图 | 方向的局地性 | 兰伯特等角圆锥 / 阿尔伯斯 | 标准纬线带内两样都近真 |
| 大地测量/工程 | —— | UTM / 高斯-克吕格(椭球保角) | 高斯本人为汉诺威测量所创(1822),Krüger 1912 给出现代公式 |
| 面积统计专题图 | 形状 | 阿尔伯斯 / 摩尔威德 / Equal Earth(2018) | 面积即数据本体 |
| 教育与世界挂图 | 极端精准 | 温克尔三重 / 罗宾森 / Equal Earth | 总失真最小化 |
| 极地工作 | 其他一切 | 方位等距 / 方位等积 | 极点无失真 |
| 航线规划 | 形状+面积 | 球心(定线)+ 等距方位(量距)组合 | 大圆=直线 vs 大圆=圆弧,各干各的 |
| 互联网地图 | 全球面积 | EPSG:3857 | 见 §5:瓦片缓存+街景保角 |
| 观念/艺术 | 实用性 | Dymaxion / AuthaGraph | 挑战"北在上"的构图权力 |

观察一下这张表就能明白 §8 的结论:**不存在"最好的投影",只存在"任务-投影"的配对。** 每一行都是一次对失真的公开选择;麻烦从来不出在配对本身,而出在把某一行的配对(比如墨卡托×世界挂图)错用到别的行里。

### 按需取径

- 只想看懂"为什么不可能画准":Snyder PP 1395 第 1-5 页 + 本文 §1 即可,无需再深;想看绝妙定理的通俗证明,任何一本微分几何教材的"Gauss curvature isometry invariance"一节都行。
- 想追 Peters 之争的一手材料:Peters(1983)与 Robinson(1985)对读,再看 Crampton(1994)收束——三方文本都有中译/易得电子版。

- 想做自己的投影比较:USGS *An Album of Map Projections*(PP 1453)有全部图形与参数;D3 的 d3-geo 与 Python 的 pyproj 都内置本文提到的全部投影,可在数分钟内画出各投影的 Tissot 指标线对照图——本文选择以文字与表格呈现,读者有兴趣可自行复现。
