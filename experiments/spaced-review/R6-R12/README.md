## 第 1 轮

**S1★ 双过程模型是哪两个过程?谁、哪年、什么机制?有没有后续修正?**【置信:高】
先答:Borbély 1982(刊物经 R9 勘误为 *Human Neurobiology*)。Process S(稳态):腺苷随清醒累积、睡眠中清除,是"睡眠压力";Process C(节律):SCN 驱动的内在昼夜节律,自由运行周期约 24.18 小时。入睡倾向 ≈ S 与 C 的**差值**;傍晚有 wake maintenance zone(C 高 S 中,不宜入睡区);2016 年更新版加了第三层——REM/NREM 比例本身也有节律。
核对 ✅:Borbély 1982 + Human Neurobiology(勘误已内化)、S=腺苷/C=SCN、24.18h、差值、WMZ、2016 第三层全中。原文另有"SCN 约 2 万神经元"未答(小漏)。

**I1★ 原文有没有印欧语支的分类清单(几支、哪些死了)?谱系篇的主线是什么?**【置信:高】
先答:没有。上轮 R9 已确认原文不做分类学:I1 当时锚空(⚠️),原文没有"分支清单"一节;安纳托利亚语支只在 Indo-Anatolian 语境出现,吐火罗全文未提。主线是历史比较法的方法论史(发现史→构拟→音变定律→树与波)+ 家乡之争(草原 vs 安纳托利亚 vs 混合)。
核对 ✅:边界记忆保持——原文确无分支清单;主线命中,且本轮核对补出上轮未记录的细节(见核对时点)。这是 6 个 ⚠️ 复用项里第一个被"巩固为边界知识"的。

**G1★ 五个时刻分别是哪五个(时间 + 事件)?**【置信:高】
