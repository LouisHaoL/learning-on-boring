# 一、盲出题方法说明

R4 行动项:"出题只看标题,不看目录"。本轮执行:**打开任何文件之前**,仅凭三篇文档的主题(学习科学/熵与热二律/经度问题)生成全部 30 问并完成作答、标置信度;此后才读 R4 记录取基线、读原文核对。过程顺序可由本文件撰写顺序与对话落盘顺序复核。

出题为 10 轮轮转(S→E→L→S→…),即"1-2-3-1-2-3"混排;作答与核对均按此混合顺序进行,未做"整篇答完再核对下一篇"的分块处理。

R4 复盘要求"薄弱四类强制加权"。本轮 30 问中,尾数/人名/年份/框架类约 20 问(67%),讽刺性细节 3 问(S5、E10、L10),远超"至少 8 问"的下限——这是有意的目标加固,直接后果之一是总体答对率必然承压(见 §4 的解读)。
